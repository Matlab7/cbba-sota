# Confirmatory test run of the frozen pre-registration (2026-09-28 to 2026-09-30)

The single run on the test split that `docs/prereg-phase1.md` (frozen at `2e53eab`, code `c8a7361`) specifies: grid
`test`, the 8 H1 settings x 50 instances, 6 lanes of 8 pinned cores on dhcho-dev-2gpus-0, 5400 jobs from 2026-09-28
22:12 to 2026-09-30 03:30 UTC. Jobs with more than 40% throttled CPU periods (42 rows, all on the two 500-task
settings in the first hours) and the 2 PCPSAT jobs whose worker timed out were re-run by a resume on the same code, as
pre-registered. Regenerated by `analyze.sh` from runs/anytime_test (gitignored, rows kept in the run archive).

- `c1_test.txt`, `c1_test.md`, `anytime_gaps_test.csv`, `anytime_ratios_test.csv`: `anytime.py report --split test
  --grid test`. Per setting, the mean gap to the best known plan per method, cores and budget, the CPU each method
  used, and the paired ratios ALNS2 / competitor with bootstrap CIs, wins-losses and Holm-corrected one-sided t-tests
  for every pre-registered family (C1 at B1: 46 tests; C1 at 2B1: 17; C2 at 0.5, 1 and 2 s: 46 each; the 8 vs 1
  worker ablation).
- `c1_test_all.txt`, `c1_test_all.md`: the same keeping the disturbed rows (sensitivity).
- `bks_test.txt`, `bks_test.csv`, `bks_test_runs.csv`, `bks_test_plans.json.gz`: the best plan per test instance
  over every run of this campaign (nothing else ran on the test split), with the best plan without any ALNS component;
  plans with 0-based routes.

Outcome: C1 holds on 8 of 8 settings (46 of 46 tests significant after Holm; ALNS2 / competitor 0.861-0.964 against
the CP-SAT-based methods, 0.876-0.946 against greedy restarts, 0.672-0.786 against the RL policy); C1 at 2B1 holds on
6 of 6 (17 of 17); C2 at 2 s holds on 7 of 8 settings (not on SA-AT-50-5-50, against parallel CP-LNS and greedy
restarts).

Correction (2026-09-30, recorded in the pre-registration): the first regeneration compared the test runs with the
validation instances' best plans, because `bks.py collect --split test` read the validation rows. The split is now
passed at call time and these files were regenerated from the unchanged campaign rows; the ratios and tests did not
change.
